# Taskora

Commercial-ready foundation for a global productivity app.

- Native Android shell
- Arabic/English UI
- Local task storage
- Search, statistics, theme control
- GitHub Actions release APK build
- Application ID: `com.taskora.app`

## Build
Push to GitHub and run **Actions → Build Taskora APK**. The generated artifact is `taskora-release-apk`.

## Monetization
AdMob and Google Play Billing should be connected with the developer's own publisher/ad/billing accounts before a public release. Placeholder architecture intentionally avoids fake ad IDs or payment credentials.
